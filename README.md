# Arizona Black — сайт и форум

Статический сайт (HTML/CSS/JS), работает на GitHub Pages без сборки.

## Структура
- index.html — главная страница
- forum.html — страница форума
- css/site.css, css/forum.css — стили
- js/site.js, js/forum.js — скрипты (ссылки и онлайн меняются в CONFIG в js/site.js)

## Как выложить на GitHub Pages
1. Создай репозиторий на github.com (например, arizona-black).
2. Нажми Add file → Upload files, перетащи ВСЕ файлы и папки из архива (index.html должен лежать в корне) и нажми Commit changes.
3. Открой Settings → Pages. В Source выбери Deploy from a branch, ветка main, папка / (root), нажми Save.
4. Через 1–2 минуты сайт откроется по адресу https://ТВОЙ-НИК.github.io/НАЗВАНИЕ-РЕПО/
